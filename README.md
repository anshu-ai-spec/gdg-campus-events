# GDG Campus Events 🌐
A simple, responsive event webpage created for the **GDG on Campus IIIT Kalyani Core Team Recruitment – Phase 2**.

## 📌 About the Project
This website presents a campus technology event and provides a simple registration form interface. It is designed to be easy to navigate on both desktop and mobile devices.

## ✨ Features
- GDG on Campus heading and logos
- Event information and venue details
- List of planned activities
- Registration form with name, email, and branch fields
- Responsive layout for mobile phones and desktops
- Simple and clean user interface

## 🛠️ Technologies Used

- **HTML5** — Website structure and content
- **CSS3** — Styling, colours, spacing, and responsive design

## 📁 Project Structures
gdg-campus-events/
├── index.html
├── style.css
└── README.md

## 🚀 How to Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Ensure you have an internet connection to load the externally hosted logos.

## 📱 Responsive Design

The website uses CSS media queries to adjust heading sizes, spacing, logo sizes, and form layout for smaller screens.
